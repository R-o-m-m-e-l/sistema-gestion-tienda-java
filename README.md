# Sistema de Gestión de Tienda e Inventario

Aplicación desarrollada en Java aplicando Programación Orientada a Objetos (POO) y persistencia/manejo de datos.

## Características Principales
- Administración y consulta del catálogo de productos.
- Control de inventario y flujo de registro de transacciones comerciales.
- Validaciones lógicas orientadas a la integridad de datos y stock.

## Tecnologías Utilizadas
- **Lenguaje:** Java
- **Almacenamiento y Persistencia:** SQL / Manejo de archivos de datos
